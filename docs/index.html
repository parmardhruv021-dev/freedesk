Everything you actually use

The full remote-desktop toolkit, without the paywall in front of it.

🖥️

Screen viewing

Hardware-accelerated AV1/VP9 streaming with adaptive quality, up to 30 fps on ordinary hardware.

🖱️

Remote control

Full keyboard and mouse control, multi-display support, clipboard sync in both directions.

🔑

Unattended access

Set a permanent password on machines you manage and reach them any time — no one needs to click “Accept”.

📦

File transfer

Browse the remote filesystem and copy files both directions inside the session.

🏠

Self-hosted by default

Points at your server out of the box. No third-party servers, no telemetry, no public STUN probes.

🔒

End-to-end encrypted

NaCl-encrypted sessions with a per-server Ed25519 identity. Your keys, your traffic.

How it works

Two small server binaries and one client. Peers find each other, punch a direct path, and relay only when they must.

Architecture

  • hbbs — ID / rendezvous server (ports 21115–21116, 21118)
  • hbbr — relay server (ports 21117, 21119)
  • freedesk — the client for controller & controlled
  • Direct P2P when possible (1 ms verified on LAN), relay as fallback

FreeDesk vs. paid remote desktop

  • ✓ Unlimited session length  ·  ✗ per-minute fees
  • ✓ Unlimited devices  ·  ✗ per-seat licensing
  • ✓ Your own server  ·  ✗ their cloud only
  • ✓ Source you can audit  ·  ✗ closed client
# run your own stack in three commands
git clone https://github.com/rustdesk/rustdesk-server && cd rustdesk-server
cargo build --release
./target/release/hbbs -r YOUR.SERVER.IP:21117 & ./target/release/hbbr &
